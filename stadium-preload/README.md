# Preloaded Stadium transformations

Pokémon Stadium picks its next transformation, and loads it, as soon as it's back to the
neutral stage, instead of when the neutral stage's timer runs out; the transformation then
starts the frame the timer runs out. Slippi's console setup does this when its Stadium
preload option is on (slippi-ssbm-asm `Common/Preload Stadium Transformations`).

```sh
tgg mod build    # a release build, packed into build/
```
