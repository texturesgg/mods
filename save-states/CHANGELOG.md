# Changelog

## 1.1.0

- Upgraded from 1 slot to 3 quick save slots: D-pad up cycles slots 1 to 3 with a compact `[1] [2] [3]` pill bar showing active and occupied slots.
- Added an optional "Auto-load on KO" setting for Free practice.

## 1.0.0

- A Luau script now, in place of the C library: one package for every platform and game layout, with nothing to compile. Plays as 0.2.2 did.
- Made for mod API 1.0, so it keeps working on every tgg-melee 1.x.

## 0.2.2

- Built again so the registry keeps it an offline mod: off in netplay, never counted. Nothing changes in the game.

## 0.2.0

- First release: D-pad left saves the match, D-pad right puts it back. Training Mode by default, and off in netplay.
- Practice > Free practice, with the Practice set.
