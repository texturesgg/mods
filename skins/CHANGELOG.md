# Changelog

## 1.0.0

- Made for mod API 1.0. It uses parts of the API that still change, so each tgg-melee update comes with a new version of it.

## 0.2.0

- Loads stage, effect and HUD skins. Online, one that changes more than looks (a stage with moved collision, say) shows the normal file in a netplay match, on your screen only.

## 0.1.1

- Built again for the registry's display class: it only changes what you see, so it doesn't count for netplay. Nothing changes in the game.

## 0.1.0

- First release: loads the skins you picked in tgg-studio. Online, a skin that changes more than looks shows the normal costume instead.
